# Contributing

Keep changes focused and preserve approved school content and unrelated design details.

1. Edit the relevant page or shared asset in `website/`.
2. Preview at desktop and mobile widths. Check keyboard navigation and reduced-motion behavior when changing interactions.
3. Run the validation commands in the README.
4. Describe what changed, why, and how it was checked in the commit or pull request.

For a website issue, include the page URL, browser/device, expected behavior, and a screenshot if useful. Do not post student information, private inquiries, passwords, or credentials in public issues.

See [the content guide](docs/content-guide.md) before updating school facts, branding, or photography.
